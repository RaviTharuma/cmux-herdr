# Plugin release checklist

After a version PR is on `main`, **push an annotated tag**. GitHub Actions
(`.github/workflows/release.yml`) runs the test suite and publishes the
GitHub Release from `CHANGELOG.md`. You do not need the GitHub UI.

Current version line: **v0.6.1** (tag after this merge). `VERSION` has no `v` prefix; the git tag does.

## Preconditions

- Version PR is merged to `main`
- `VERSION` contains `X.Y.Z`
- `CHANGELOG.md` has a `## [X.Y.Z]` section
- `./scripts/test.sh` is green

## Publish

```bash
./scripts/test.sh
./bin/cmux-herdr --version   # must print cmux-herdr X.Y.Z
git checkout main
git pull origin main
git tag -a vX.Y.Z -m "cmux-herdr vX.Y.Z"
git push origin vX.Y.Z
```

The `release` workflow then:

1. Re-runs `./scripts/test.sh`
2. Checks that the tag equals `v` + `VERSION`
3. Creates or updates https://github.com/RaviTharuma/cmux-herdr/releases

Notes are generated by `python3 scripts/changelog_notes.py vX.Y.Z`.

Optional live smoke (macOS, Herdr nested in cmux):

```bash
./bin/cmux-herdr doctor
./bin/cmux-herdr status
./bin/cmux-herdr tree
./bin/cmux-herdr sync
```

## Install from the tag

Official install is the plugin manager plus the CLI (not a custom-sidebar copy):

```bash
cmux sidebar plugin install https://github.com/RaviTharuma/cmux-herdr.git
cmux sidebar plugin use cmux-herdr
cmux-herdr --version
cmux-herdr doctor
cmux-herdr watch
```

Contributor clone of a tag (not the user path):

```bash
git clone --branch vX.Y.Z --depth 1 \
  https://github.com/RaviTharuma/cmux-herdr.git
cd cmux-herdr
./scripts/install.sh
```

Install paths (plugin manager clones into `$XDG_DATA_HOME/cmux/mux-plugins/cmux-herdr`;
`install.sh` is the contributor symlink):

| Artifact | Path |
|---|---|
| CLI | `~/.local/bin/cmux-herdr` |
| Custom sidebar leftover | `~/.config/cmux/sidebars/herdr.js` / `herdr.swift` (demoted; uninstall deletes) |
| Agent skill | `~/.agents/skills/cmux-herdr/` (and/or `~/.pi/agent/skills/cmux-herdr/`) |
| LaunchAgent plist | `~/Library/LaunchAgents/com.cmux-herdr.watch.plist` |
| Watch logs | `~/Library/Logs/cmux-herdr-watch.{out,err}.log` |
| Association cache | `~/.local/state/cmux-herdr/` |

## Version bump

1. Edit `VERSION` (e.g. `0.3.5` or `0.4.0`).
2. Move `[Unreleased]` notes into a new `CHANGELOG.md` section.
3. Merge to `main`, then tag `vX.Y.Z` as above.

Do not expand this plugin into [manaflow-ai/cmux#8737](https://github.com/manaflow-ai/cmux/issues/8737).
