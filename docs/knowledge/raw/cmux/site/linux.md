cmux Browser


A Chromium browser and agent workspace, built together.

A native x64 build with Chromium tabs, cmux workspaces, and integrated terminal surfaces.

[Download auto-updating installer (.run)](https://cmux.com/api/download/browser-nightly/linux-x64/run) [Debian package (.deb)](https://cmux.com/api/download/browser-nightly/linux-x64/deb)

Linux · x64

## Built for agentic work

-   **Real Chromium**: Chrome-quality tabs, rendering, extensions, and omnibox behavior
-   **Task-shaped workspaces**: organize web tabs and tools around the task instead of one endless tab strip
-   **Terminal surfaces**: keep shells and browser tabs in the same window and compositor
-   **Free and open source**: inspect the code, file issues, and build from source on GitHub

## Install

Run the per-user installer once. It installs under ~/.local without root and enables signed in-app updates. Choose the Debian package instead if you want updates managed by your package manager.

```
chmod +x cmux-linux-x64-installer.run
./cmux-linux-x64-installer.run
```
