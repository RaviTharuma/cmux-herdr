# cmux NIGHTLY

![cmux NIGHTLY icon](https://cmux.com/logo-nightly.png)


cmux NIGHTLY is built automatically from the latest commit on main. It has its own bundle ID, so it runs alongside the stable version without conflicts. Use it to test new features before they ship.

[Download NIGHTLY for Mac](https://github.com/manaflow-ai/cmux/releases/download/nightly/cmux-nightly-macos.dmg)

Nightly builds may contain bugs or incomplete features. If something breaks, report it on [GitHub](https://github.com/manaflow-ai/cmux/issues) or in [#nightly-bugs on Discord](https://discord.gg/xsgFEVrWCZ), and switch back to the stable release.

Canonical: https://cmux.com/nightly
