Coding-agent threads reach useful fork points. You may want to keep one approach intact while another agent tries a different implementation, investigates a tangent, or reviews the same problem from a fresh angle.

Fork Conversation creates a new agent session from the current thread, preserving its conversation history and working directory. It supports Codex, Claude Code, OpenCode, Pi, Hermes, and other agents with forkable sessions.

## Fork wherever you want to work

Right-click a terminal or tab and choose Fork Conversation, or press `Cmd+Shift+P` and search for Fork Conversation. Send the fork to a split on any side, a new tab, or a new workspace.

## Explore several directions at once

Fork the same conversation more than once to compare implementations or let several agents divide a problem with the same starting context. Each fork continues independently, while the original thread stays available.

Forks can work in the same directory. Give them separate tasks or files when concurrent edits could overlap.

cmux Fork is available in v0.64.19.
