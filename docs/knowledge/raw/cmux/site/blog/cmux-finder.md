cmux now has a Finder-style file explorer in the sidebar.

It previews videos, images, PDFs, and markdown files inside cmux, so you can inspect generated artifacts without leaving the workspace.

I use it most for demo videos and screenshots that Codex records while it is testing changes.

Toggle file previews from Cmd+Shift+P, then choose Enable Cmd-click File Previews or Disable Cmd-click File Previews.

Requires cmux v0.64+.
