# A better markdown viewer in cmux

[← Back to blog](https://cmux.com/blog)


[![](https://cmux.com/_next/image?url=%2Favatars%2Flawrencecchen.jpg&w=64&q=75&dpl=dpl_AT5HfVg9fuRYjj7rCgqhY9VxGYH8)Lawrence Chen@lawrencecchen](https://x.com/lawrencecchen)May 22, 2026

cmux has a better markdown viewer for README files, docs, and generated reports.

Open a file from the CLI:

```
cmux open README.md
```

You can also drag a markdown file from the right sidebar into the workspace.

Thank you [@tobi](https://github.com/tobi) for the contribution.
