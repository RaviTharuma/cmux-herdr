# Project governance

**cmux-herdr** is maintained by [@RaviTharuma](https://github.com/RaviTharuma).

## Decision making

- The maintainer has final say on scope, merges, releases, and issue closure.
- Contributions are welcome under [CONTRIBUTING.md](CONTRIBUTING.md) and the
  [Code of Conduct](CODE_OF_CONDUCT.md).
- "Not in scope for the plugin; see [OPEN.md](OPEN.md)" is a valid close.
- Native cmux / Herdr work does not land here; keep it on the upstream or
  fork repos listed in [docs/MAINTAINING.md](docs/MAINTAINING.md).

## Roles

| Role | Who | Responsibilities |
|---|---|---|
| Maintainer | `@RaviTharuma` | Reviews, releases, CoC enforcement, security advisories |
| Contributor | Anyone with a merged PR or accepted issue | Follows contribution and conduct rules |

There is no formal steering committee, RFC board, or committer ladder yet.
If that changes, this file will be updated.

## Releases

Tagged releases (`vX.Y.Z`) are the supported artifacts. Process:
[RELEASE.md](RELEASE.md). Security fixes prefer a patch release when practical.

## Conflict of interest / affiliation

This plugin is independent of the cmux and Herdr projects. See
[DISCLAIMER.md](DISCLAIMER.md).
