# Glossary

| Term | Meaning |
|------|---------|
| **cmux-herdr** | cmux plugin that surfaces Herdr pane viewers and agent status |
| **cmux** | Terminal / agent workspace UI this plugin extends |
| **Herdr** | Terminal workspace manager for AI coding agent seats |
| **attach-pane** | Plugin command for external Herdr pane viewers |
| **status pill** | Live sidebar indicator of agent/seat state |
| **DEV-001** | Canonical coding host label |
